# Fifield Digital official website

Static responsive site for GitHub Pages. Upload the contents of this folder to the root of a GitHub repository (not the enclosing folder). In GitHub: Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save. The URL will normally be `https://YOUR-USERNAME.github.io/REPOSITORY/` (or `https://YOUR-USERNAME.github.io/` for a repository named YOUR-USERNAME.github.io). Wait until GitHub reports successful deployment and check all pages on mobile.

Before submitting to Stripe: verify the legal business name, contact email, service descriptions, published refund and privacy terms, and add accurate product pricing and purchase/checkout information if accepting online purchases. Stripe makes its own verification decision. Do not claim a subscription or trial is live until payment and access controls are implemented. If you use a different hosting platform, review and update the hosting paragraph of privacy.html. Replace the email address in all pages if your business contact changes. These policy templates should be reviewed for your actual operations and jurisdiction.

No payment or contact-form backend is included. Contact links open an email application. Do not upload credentials or Stripe secret keys to this repository.
